OpenSL1 – unofficial Rane SL1 driver for macOS

This installer sets up a free CoreAudio driver for the Rane SL1 (Serato Scratch Live). Afterwards the SL1 shows up as the audio device “Rane SL1” with 4 inputs (Input 1/2) and 4 outputs (Line 1/2), for example for timecode vinyl.

Which DJ software works?

  • Mixxx (free): works, timecode on both decks tested with Serato CV02 vinyl.
  • VirtualDJ: works as a sound card (tested). Its timecode feature needs a paid VirtualDJ licence and has not been tested.
  • Serato Scratch Live is legacy software and does not run on Apple Silicon. Serato DJ Lite/Pro do not accept the SL1. OpenSL1 will never present the SL1 as another device.

The driver is copied to /Library/Audio/Plug-Ins/HAL/OpenSL1.driver. The macOS audio server restarts afterwards, so running audio apps will drop out for a moment. This installer is not “notarized”, i.e. not checked by Apple, because that needs a paid developer account; that is why macOS may have shown a warning. The source code is public at github.com/OnSerious/OpenSL1.
